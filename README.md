# Rock Paper Scissors

A simple rock-paper-scissors game built with JavaScript. 

## About The Project
This project was created as part of The Odin Project's Foundations curriculum. The main goal was to build a functional game running in the console (or browser) to practice foundational programming concepts.

## What I Learned
Building this game served as a great practical exercise to understand core JavaScript mechanics, specifically:
* Using conditional logic (`if/else` statements, operators) to determine the winner.
* Writing, structuring, and calling functions.
* Breaking down problem-solving steps and implementing game rules in code.
